# Sistema de Gestión - Programación Avanzada

Proyecto desarrollado en Python aplicando Programación Orientada a Objetos (POO), modularización de archivos y gestión de datos en memoria para la Universidad Francisco de Paula Santander (UFPS).

## Ítems implementados:
- **Uso de clases:** Clases `Productos`, `Clientes` y `Gestor_base_datos`.
- **Métodos y constructores:** Implementación de constructores (`__init__`) y métodos lógicos y de visualización.
- **Estructura de archivos:** Código dividido en módulos separados (`producto.py`, `cliente.py`, `database.py`, `main.py`).
- **Visualización:** Interfaz interactiva de consola en el archivo principal.

## Ejecución
Ejecuta el siguiente comando en la terminal para iniciar el sistema:
```bash
python main.py
```
